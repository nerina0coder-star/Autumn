# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, email github.py.coder@gmail.com or use GitHub's "Report a Vulnerability" button, with:

- A description of the issue
- Steps to reproduce
- Affected versions
- Any potential impact

We will acknowledge your report within 3 to 10 business days and aim to provide
a fix or mitigation plan within 30 days.
